# #12: Is `1H` supposed to work?

**opened by abello, 2024-05-02 — closed**

`parse_duration("1H")` returns 3600. Our linter flagged upper-case units in a config file and I
expected timeparse to reject them too. Is this on purpose?

**priya-n**, 2024-05-03:

We rely on it: our operators type `30M` all the time.

**jrivera** (maintainer), 2024-05-04:

On purpose, see D-4. Units are case-insensitive; whitespace inside a duration is not allowed.
