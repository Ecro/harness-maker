## [wiki:gotcha] add-f-for-new-memory-files | 2026-05-16
`.claude/` is gitignored at line 13 of `.gitignore`. Existing `.claude/memory/*.md` files (wiki.md, failures.md, pending-drift.md, session/YYYY-MM-DD.md) are tracked via historical `git add -f` invocations — no negation rule like `!.claude/memory/` in the gitignore. NEW files created in `.claude/memory/` will NOT be picked up by `git add -A` or `git add -u` — they need explicit `git add -f <path>`. Symptom: wrapup agent reports "session/2026-05-16.md written" but `git ls-files` shows it missing post-commit; worktree cleanup then destroys the file. Fix pattern: in wrapup, force-add new memory files explicitly. Also applies to any new memory subdirectory file (e.g. `.claude/memory/episodic/foo.md` would also need force-add).
