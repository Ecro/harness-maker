## [decision:install-without-claude-code] Split try/except in _compute_install_ref for correctness | 02:10 UTC | stage:wrapup
Review caught a P1: the original single `except Exception` conflated "package not found" (→ local path) with "JSON parse error on installed wheel" (→ should be PyPI name). On a wheel, `_HARNESS_MAKER_PKG_ROOT` resolves to `site-packages` parents, producing an invalid `--with` ref. Split into two blocks: outer catches distribution failure (→ local path), inner catches JSON errors (→ `"harness-maker"`). This distinction is subtle but load-bearing for every rendered hook and command.
