## [decision:deep-interview-gate] skip-guard placement is the load-bearing UX contract | stage:wrapup
The 3-layer gate's key architectural decision was that skip guards must be evaluated FIRST in each gate instance — before any GCIC scoring — and must honor signals from EARLIER rounds in the SAME session, not just the current round. The UX review caught that a user who signals "SPEC is sufficiently clear" in §2.1 round 1 should never encounter the gate in §2.5 at all. This is fundamentally different from convergence logic (which cares about consecutive rounds); the skip guard is a session-level one-way latch. Second key decision: Layer 2 type labels must be stable identifiers (WRONG/METHOD/STAKEHOLDER/STYLE/PERF) rather than semantic descriptions, because LLM "MUST NOT ask the same type" needs an exact-match rule it can enforce reliably over possibly-compacted context. Score monotonicity rule required explicit output target (`[score-drop-reason]: ...` appended to Layer 3 display block) or else LLM has nowhere to write the note and may silently skip or block.

## [decision:codex-target-support] body-partial refactor was the load-bearing unlock for TOML agent files | stage:wrapup
The main architectural surprise was ADR-007: all 12 agent `.md.j2` templates had to be split into `<name>.md.j2` (YAML frontmatter + `{% include _body.md.j2 %}`) and `<name>_body.md.j2` (content only). Without this, `{% include %}` in the TOML template would embed the YAML `---\nname:...---` frontmatter as literal text inside `developer_instructions`. The refactor was forced even though it touched 24 files (12×2), because there is no clean alternative — escaping YAML in Jinja2 only works if the frontmatter is entirely static, which it's not. Key trade-off accepted: 24 template files instead of 12, but the invariant "TOML `developer_instructions` = pure Markdown, no YAML contamination" is now guaranteed at render time. Review grade A (no consensus-passed findings). 4 high-priority review findings applied in wrapup: TOML quoted-key for MCP server names (M-SEC-1), `@hm-spec`/`@hm-verify` added to AGENTS.md stage list (M-UX-1), `consensus:`→`verbosity:` label fix (M-UX-2), reconcile TOML fast-path so config updates propagate (M-CODE-1).
